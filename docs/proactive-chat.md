# 積極主動對話模式

在「主動互動」選擇角色，勾選「允許此角色主動搭話」，將主動程度設為
「積極（依回覆速度調整）」並儲存。選擇模式本身不會開始傳訊息；使用者下一次
主動聊天後，角色才進入第一檔。

| 檔位 | 主動訊息間隔 | 從角色實際送出訊息後計算的回覆規則 |
|---|---|---|
| 第一檔 | 5±2 分鐘 | 5 分鐘內回覆維持第一檔；未回覆降第二檔 |
| 第二檔 | 10±2 分鐘 | 5 分鐘內回覆回第一檔；5～10 分鐘維持第二檔；未回覆降第三檔 |
| 第三檔 | 15±2 分鐘 | 5 分鐘內回第一檔；5～10 分鐘回第二檔；10～15 分鐘維持第三檔；未回覆退出積極狀態 |

收到回覆後，下一則訊息從回覆時間起，按選定檔位重新排程。沒有回覆而降檔時，
下一則訊息的間隔從上一則角色訊息的實際送出時間起算。每次排程僅抽一次隨機間隔，
並保存至聊天資料庫；重啟或重複檢查不會重新抽取。等待回覆的期限內不再追加訊息。
恰好在 5、10、15 分鐘期限內的回覆算作有效回覆。

積極狀態退出後，使用者再次聊天會重新從第一檔開始。切換為其他主動程度或取消允許
主動搭話，也會退出。靜默時段繼續生效；積極模式不套用一般模式的每日則數上限。
主動訊息不播放 TTS、不計為使用者聊天，也不增加好感度。

訊息必須成功產生並保存後，才開始回覆倒數；產生失敗沿用既有重試機制。
若訊息仍在產生時使用者已聊天，舊的主動訊息會失效，避免晚到的內容打斷新一輪對話。
